# Product shelf

Own user-facing behavior and terminology.

## Inputs

Choose only the reference that answers the request:

| Question | Read |
|---|---|
| Access, creation, membership, ownership, policies, limits | [Routes and membership](routes.md) |
| Sharing, presence, GPS quality, recovery | [Tracking](tracking.md) |
| Layout, map interaction, sharing links, timestamps | [Experience](experience.md) |

## Process

Read the current request and chosen reference. Resolve terminology here; record technical wiring in system references. Read the relevant [delivery gap](../planning/status.md#specification-versus-implementation) only when the request depends on whether a requirement is implemented.

## Outputs

Edit the relevant reference and keep [MVP routing](../mvp-spec.md) current.
