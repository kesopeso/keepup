BEHAVIOR TO REVIEW

A route appears once, with a clear next step

Three additive filters

My routes = owned. Joined routes = current non-owner membership. Left routes = former membership, off by default. Current membership takes precedence over an older left episode.

Left does not mean access

Rejoin goes through normal access checks. A protected archive also checks access before opening. The list shows a minimal summary, never participant locations.

Back takes you back

Returning from a route restores the tab, filters, and list position for this session. A fresh visit starts on Active with the default filters. Signing out clears view state.

Proposed ordering: newest created active routes first; newest closed archives first. Server pagination: 20 per page, then Load more. This small mock dataset fits on one page. Loading and errors are explicit preview states.
