# Architecture decision records

This pre-existing shelf has no decision records yet; its .gitkeep is retained.

## Inputs

Read [system design](../architecture.md), the relevant source files, and the requested decision.

## Process

Record a consequential architectural choice here when a task calls for one, using the [note template](../_templates/note.md). Explain context, alternatives, decision, and consequences. Link current behavior to its system reference rather than duplicating it.

## Outputs

A dated Markdown decision record and a link from the affected system reference.

## Human check

Verify the decision and tradeoffs before treating a proposal as adopted.
