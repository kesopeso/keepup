# Architecture decision records

Record consequential architectural choices and their review state.

| Decision | State |
|---|---|
| [0001: Account authentication and route identity](0001-account-authentication.md) | Accepted; account/Google/route backend implemented, live leases/revocation implemented; client integration pending |

## Inputs

Read only the relevant system reference, source files, and requested decision. This shelf is loaded for decision reasoning, not routine startup or documentation checks.

## Process

Record a consequential architectural choice here when a task calls for one, using the [note template](../_templates/note.md). Explain context, alternatives, decision, and consequences. Link current behavior to its system reference rather than duplicating it.

## Outputs

A dated Markdown decision record and a link from the affected system reference.

## Human check

Verify the decision and tradeoffs before treating a proposal as adopted.
